# Machine Learning Projects

A collection of machine learning projects implemented with Python, NumPy, Pandas, and Matplotlib. The projects cover regression, classification, dimensionality reduction, and ensemble learning.

## Projects

### 1. Understanding and Training Regression Models

[View Project 1](./Project1.ipynb)

- Implemented linear and generalized linear regression models from scratch using NumPy and Pandas to analyze movie ratings and housing prices. Applied gradient descent, stochastic gradient descent, normal equations, feature transformations, mean squared error evaluation, and model visualization.

### 2. Classification Models

[View Project 2](./Project2.ipynb)

- Built binary and multiclass logistic regression models from scratch using NumPy and Pandas to classify student success and iris species. Applied gradient descent, feature scaling, stratified sampling, 5-fold cross-validation, and decision-boundary visualization.

### 3. PCA and LDA Image Classification

[View Project 3](./Project3.ipynb)

- Implemented PCA and Linear Discriminant Analysis from scratch using NumPy and Pandas for image representation and classification. Applied image vectorization, data centering, dimensionality reduction, nearest-neighbor pose estimation, and subspace learning to classify Boat images and MNIST digits while comparing PCA and LDA class separation.

### 4. Decision Trees and Random Forests

[View Project 4](./Project4.ipynb)

- Implemented and evaluated Decision Tree and Random Forest classifiers to predict Titanic passenger survival. Applied preprocessing, feature engineering, information gain, bootstrapping, and ensemble learning to improve classification accuracy through aggregated predictions.
